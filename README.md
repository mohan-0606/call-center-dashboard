📞 CALL CENTER DATA ANALYSIS DASHBOARD

📌 Project Overview

This project focuses on analyzing call center operations and performance using an interactive dashboard. It provides insights into customer interactions, call volumes, agent performance, and customer satisfaction.

🎯 Project Objectives

* Analyze total incoming calls.
* Monitor answered and unanswered calls.
* Track average call duration.
* Evaluate agent performance.
* Analyze customer satisfaction.
* Identify monthly call trends.

🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Data Visualization

📊 Key Performance Indicators (KPIs)

* Total Calls
* Answered Calls
* Happy calls
* Average Call Duration
* Customer Satisfaction Rating

📈 Dashboard Features

* Call volume analysis
* Agent-wise performance
* Call status analysis
* Customer satisfaction analysis
* Monthly and daily call trends
* Interactive dashboard filters
